## 🤖 Overview

AutoActions monitors the active foreground window and system state, firing custom scripts and hotkeys automatically when you switch between applications.

Whether you're a newcomer or a veteran, AutoActions provides the tools you need to get the most out of your ai tools experience. Designed for Windows and macOS, it delivers a seamless, high-performance workflow.

## ✨ Key Features

| Feature | Description |
|---|---|
| **Window Detection** | Trigger actions when specific apps gain or lose focus |
| **Script Runner** | Execute PowerShell, batch, or AutoHotkey scripts on events |
